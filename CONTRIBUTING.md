# Contributing to DataShield

## Getting started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/DataShield.git`
3. Install dependencies: `npm install`
4. Create a branch: `git checkout -b feat/your-feature`

## Commit conventions

This project follows [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:` — new feature
- `fix:` — bug fix
- `chore:` — maintenance, dependencies, config
- `docs:` — documentation only
- `refactor:` — code change that is not a fix nor a feature

## Pull requests

- One feature per PR
- Keep the PR description clear and concise
- Reference any related issue with `Closes #issue-number`

## Code of conduct

Please read [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) before contributing.
