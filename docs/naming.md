# Project naming

This project was originally released under the name **DataShield**. It was
renamed to **Gardik** in September 2026.

## Why the name changed

The DataShield name was already in use several times over:

- `D DATASHIELD` is a registered US trademark, registration number 4524747,
  held by Datashield Corporation.
- DataSHIELD is an established open-source project for federated analysis of
  sensitive data. It works in the same broad field as this project, which made
  confusion likely.
- A managed detection and response vendor operated under the Datashield name
  before becoming ADT Cybersecurity.
- Every namespace was taken: the `.com`, `.io`, `.org` and `.net` domains, the
  npm and PyPI package names, the Docker Hub namespace and the GitHub
  organisation.

Gardik was chosen because it was free across all of those, and because it is
built on the root `guard`.

## What you may still see

Older commits, tags, branches and pull requests can still mention DataShield.
**This is expected and harmless.** DataShield was the original name of this
same codebase, not a different project.

Everything in the current source tree uses Gardik: the display name, the
package name, the container and volume names, the database name, the seed and
fixture addresses, the export file prefixes and the repository URLs.
